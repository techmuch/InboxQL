About this screen

Purpose. A question in plain words, answered by the agent CLI you already use (Claude Code, agy), running on this computer with the iql skill. The answer is never only prose: it comes with the results it rests on and the exact commands it ran, so it can be checked, kept or turned into a query.

Callouts

  1. 1 It always says who answered, how long it took, and how much it read. What was sent to the agent’s provider is in the evidence panel.
  2. 2 The answer comes first, in sentences, with every figure in bold so the eye finds the numbers.
  3. 3 Evidence, not trust. The rows and the quoted line the answer rests on are shown, each linked to its message or file.
  4. 4 An answer can become something lasting: a section on a subject, a saved query, or a reminder. The agent only proposes; you press the button.
  5. 5 A follow-up continues the same agent session.
  6. 6 While it works, its steps are listed in words from the commands it runs, in a polite live region announced step by step, with Stop.

What changed from today's app

  • New. Asking in words replaces nothing: the query bar still runs queries; words that are not a query get two choices.
  • Answers go through the agent CLI rather than InboxQL’s own AI provider settings, so there is one place your mail goes and one account to pay for.
