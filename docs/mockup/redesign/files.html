About this screen

Purpose. Every file that arrived or left by mail, as files rather than as attachments: one row per distinct file, with how many times it was sent and whether InboxQL could read inside it.

Callouts

  1. 1 The sentence says how many files have not been read, because “no file says that” and “nobody looked” are different answers.
  2. 2 Inside says what InboxQL knows about the contents: read, a scan that needs OCR, an image with no text, or not read yet — and what the agent extracted from it.

What changed from today's app

  • Files also appear in each subject’s stream, filtered to that subject.
  • Previews open in the right-hand panel, not a new tab.
