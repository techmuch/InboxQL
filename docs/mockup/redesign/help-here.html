About this screen

Purpose. ? on any screen opens its own help in a panel at the side, without leaving the screen: what it is for, what each section is, and the keys that work here — as you have them, including keys you changed.

Callouts

  1. 1 One sentence: what the screen is for.
  2. 2 Each section named as it appears on the screen, with a link that moves focus to it — so the help also works as a map.
  3. 3 Only the keys for this screen, not all of them. Changed keys are shown as changed.
