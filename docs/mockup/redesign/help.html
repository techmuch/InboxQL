About this screen

Purpose. One place for every guide, the release notes and the keyboard reference, all built into the binary — so help is always about the version you have, works offline, and is the same text iql help prints.

Callouts

  1. 1 Says the version the guides describe, and that nothing is fetched.
  2. 2 Help where you are is the main way in: ? on any screen opens that screen’s own help (the same content these mockups show under each screen), and Settings rows, agent conclusions and error messages link to their paragraph.
  3. 3 What’s new shows the release you are running. After an update, Today shows one line — “Updated to 2026.11.1.1 · What’s new” — once, and dismissing it does not hide the notes here.

What changed from today's app

  • Help → Documentation today is a list of Markdown files in a viewer tab; it becomes a page in the three-part layout.
  • Search covers guides, release notes, keyboard keys and settings together, and offers Ask in words for “how do I…” questions.
