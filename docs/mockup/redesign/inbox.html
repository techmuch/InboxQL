About this screen

Purpose. The mailbox as a list, for when you want to go through mail yourself rather than by subject. It is a query — folder:inbox — with filters that add terms to it, so anything you can do here you can save as a subject.

Callouts

  1. 1 The sentence says what is in the inbox and what the agent has not read, before any rows.
  2. 2 Filters are toggle buttons; each one shows the term it adds, so the query bar teaches the language.
  3. 3 Selection works as now (x, shift-click, select all matching). Changing a filter clears the selection and says so.

What changed from today's app

  • The Desk’s rail, query and results columns become this page plus Subjects in the navigation.
  • “By subject” groups the inbox the way Today does, for an inbox-zero pass.
  • Opening a message goes to the Conversation page in the middle column; the right column shows the selected one’s summary.
