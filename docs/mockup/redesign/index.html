The layout

Three fixed parts on every screen, replacing the tab-and-pane workspace. Free-form tabs are gone; there is no expert mode.

The evidence panel is resizable. Drag the divider on its left edge, or Tab to the divider and use ← → (Shift for bigger steps, Home/End for narrowest and widest). Enter on the divider, or . anywhere, hides and shows it; dragging it nearly shut hides it; a double-click resets it. The width is the same on every screen and is remembered. It is a standard window splitter, so a screen reader hears “Resize the evidence panel, separator, 352 pixels wide” and each change. Try it on any screen in these mockups. Below 1100 px the panel moves under the screen and the divider goes away.

How to read these mockups

  • Static HTML, made-up people and data; nothing talks to a server. Buttons don't do anything.
  • Each screen has an About this screen section below it: purpose, numbered callouts (1), keyboard, screen reader, and its workflows.
  • Use “Show dark theme” in the banner to check both themes. Narrow the window to see the tablet and phone layouts.
  • planned marks something not built in InboxQL today.
