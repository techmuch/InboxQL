About this screen

Purpose. Objective 5, fewer places. With subjects replacing most destinations, the way to anywhere is to type its name. ⌘K from any screen. The navigation column stays, holding only what you pinned and the four Needs-me entries.

What it finds

  • People and organizations, ranked by how recently and how much you correspond — not alphabetically.
  • Subjects: topics, labels, saved queries, cards.
  • Actions that apply to the top match (“Reply to Rafael”) and global ones (“Go to Calendar”, “Switch theme”).
  • Queries: the text as a full-text search, and a structured guess. Choosing one opens Ask with that query — shown, never run unseen.

Screen reader

The ARIA combobox pattern: a modal dialog, an input with aria-activedescendant pointing at the highlighted option, group labels as presentation rows. Each option's text says its kind first. The count of matches is announced politely after typing pauses.
