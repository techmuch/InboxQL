About this screen

Purpose. Objective 4, the query is the interface. This is today's Desk and Dashboard combined: any view in the app opens here as its query, shown three ways at once — the text in the app bar, removable terms in plain words, and the results.

Callouts

  1. 1 A plain-language sentence of what the query means and how many it found. When Trash or Spam are left out, it says how many matched there.
  2. 2 Terms as chips, named in words (“not from me”, not -from:me()). Removing one edits the text; typing in the text updates the chips. Suggestions are the terms most likely to narrow this result.
  3. 3 “Show as” replaces the pipeline stage: Messages, Conversations (| timeline), a total, a grouping, a count. Every chart has a table view and a sentence summary; colour is never the only encoding.

Hand to an agent

Copies a ready instruction — for example iql work next --query "extract:receipts after:2026-01-01 -from:me()" — or, with a connected agent, starts it. The agent's results come back as proposals in To review.

Ask in words planned

Typing a question in the query bar (“what did I spend on the kitchen?”) asks the configured model to write the query, and shows the query for you to run. It never runs a query you have not seen, and with no model configured the bar only accepts the language.
