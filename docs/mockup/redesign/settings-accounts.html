Keyboard

KeyDoes
TabMoves through settings in order; every control has a visible label

Screen reader

Each setting is a label, a description (linked with aria-describedby) and a control. The segmented choices are radio groups in a fieldset named by the setting.

From the command line

Everything on this page can also be done with iql, so a script or an agent can read it — and the change shows here.

  • iql --json account list
    accounts, never with passwords
  • iql account verify personal
    test one; says why it failed
  • iql --json calendar accounts
    connected calendars

When changes apply

At once. Changing an account’s server asks for its password again — a password for one server is never sent to another.
