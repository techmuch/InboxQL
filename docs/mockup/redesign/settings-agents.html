AI provider

Where summaries and drafts are written

None: nothing is summarised or drafted for you, and nothing leaves this computer. On this computer: a local model does it. Remote: the text of a conversation is sent to the provider each time — you are shown where, and asked once, before the first.

Local models

GLiNER extracts values (800 MB) · Laya judges yes/no (1.2 GB). Both run here and send nothing.

From the command line

Everything on this page can also be done with iql, so a script or an agent can read it — and the change shows here.

  • iql --json llm status
    which provider, local or remote
  • iql --json elements list
    elements and what is answered
  • iql --json work targets
    accuracy targets and cost
  • iql skills list
    assistants with the iql skill

When changes apply

At once. A remote provider is used only after you confirm what will be sent and where.
