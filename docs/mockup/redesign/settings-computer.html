From the command line

Everything on this page can also be done with iql, so a script or an agent can read it — and the change shows here.

  • iql --json service status
    installed, running, address
  • iql --json update --check
    newer release?
  • iql --json ui list
    open windows
  • iql --json log level
    logging level and dropped lines
