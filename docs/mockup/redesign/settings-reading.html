About this screen

Purpose. How InboxQL looks and reads. Accessibility settings are not a separate “accessibility” page — text size, motion, spacing and shortcuts sit with the rest of how things look, because everyone uses them.

Callouts

  1. 1 Text size scales the whole interface. At 150% the three parts become two, then one, rather than truncating.
  2. 2 Every screen has the same three parts. There is no tab workspace and no expert mode; the only layout choice is the evidence panel — shown or hidden, and how wide.
  3. 3 Single-character shortcuts can be turned off or remapped (WCAG 2.1.4), which matters for speech input and screen-reader quick-navigation keys.

What changed from today's app

  • General (theme, inbox layout, previews, rail entries) becomes this page.
  • Text size, spacing, motion, week start, time format, reminders and the shortcut settings are new.
  • The rail arrangement becomes “Subjects in the navigation”.

Screen reader

Theme swatches are a radio group named “Theme”; each swatch’s name is its theme. A changed setting says “changed” with a Reset link next to its label.

From the command line

Everything on this page can also be done with iql, so a script or an agent can read it — and the change shows here.

  • iql saved move <name> top
    order of subjects in the navigation
  • iql saved folders hide spam
    hide a mailbox row

When changes apply

At once, in this window and every other open one. Stored in this browser except the subjects order, which is in the mailbox.
