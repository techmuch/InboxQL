About this screen

Purpose. Settings is a place in the navigation like any other, with one overview. The overview leads with what needs you and says each section’s state in a line, so most visits end here.

Callouts

  1. 1 A sentence of state. A healthy install says so; a problem names itself and the fix.
  2. 2 Six sections instead of eleven, named for what you are doing (accounts, agents, reading, your data, this computer) rather than for the code behind them. Each line is that section’s current state, not a description of it.
  3. 3 Find a setting searches labels and keywords, as now, and says where the result lives and its current value. Choosing one opens the section and moves focus to the setting.

What changed from today's app

  • Profile, Accounts and Calendars → You and your accounts.
  • AI Configuration, Annotators, Elements and the work-loop targets → Agents and AI.
  • General (theme, inbox layout, previews, rail) → Reading and appearance, which gains text size, motion and shortcut settings.
  • Import, Data management, Maintenance, Storage → Your data.
  • System and Logging, and the Windows tab → This computer.

Screen reader

Settings has its own navigation landmark (“Settings sections”) after the main Places navigation. A section with something wrong says “needs attention” in its link name, not only with a badge.

From the command line

Everything on this page can also be done with iql, so a script or an agent can read it — and the change shows here.

  • iql --json doctor
    the same health checks as “Needs attention”
  • iql --json where
    which mailbox, and why
  • iql --json update --check
    is there a newer release

When changes apply

Each setting says when it applies. Most apply at once; a few need a restart and say so.
